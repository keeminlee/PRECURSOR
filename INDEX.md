# PRECURSOR Index

`PRECURSOR/` is the enterprise-safe, human-governed adjunct lane for Copilot-native Plan -> Execute -> Closeout work.

## Start Here

- `README.md` - lane overview and quick start.
- `START_HERE.md` - setup and first-run path.
- `MANIFEST.md` - complete package inventory.

## Core Surfaces

- `SKILLS/` - Plan, Execute, Closeout, bootstrap, config, and optional daily ritual skills.
- `.github/agents/` - Copilot agent wrappers.
- `demo/` - simple docs-only demo.
- `demo-interactive/` - interactive artifact-verification demo.
- `graphify-out/` - generated graph output.

## Operating Shape

Human-gated transitions are the point. No autonomous chaining unless an explicitly experimental path says so and its preconditions are met.

## Boundaries

PRECURSOR complements RECURSOR; it does not replace canon or RECURSOR governance.
